## المحتوى

- **الأسماء الحسنى (99)**: ساعة دوّارة تعرض اسمًا كل تكّة بالعربية والإنجليزية مع معنى مختصر بخطوط خفيفة، لمساعدة على الحفظ والقراءة.
- **السبحة**: مسبحة متحركة مع صوت خرزات عند كل تقّة، واختيار الذكر (سبحان الله / الحمد لله / الله أكبر / أستغفر الله) واختيار العدد (33 أو 100).
- **واجهة عربية بسيطة** مع تنقّل سريع بين الشاشات وإعدادات يمكن تعديلها.

## الرابط المباشر

افتح التطبيق من هنا:

```
https://USERNAME.github.io/REPO-NAME/
```

> استبدل `USERNAME` باسم مستخدمك على GitHub، و`REPO-NAME` باسم المستودع. ستجد الرابط الصحيح يظهر تلقائيًا في صفحة Settings ثم Pages بعد تفعيل GitHub Pages.

## كيف أُحدّث التطبيق لاحقًا؟

1. افتح المستودع على GitHub.
2. اضغط **Add file** ثم **Upload files**.
3. اسحب ملف `index.html` الجديد ليحلّ محل القديم.
4. اضغط **Commit changes**.
5. بعد دقيقة تقريبًا سيتحدّث الرابط تلقائيًا.

## التشغيل محليًا

حمّل ملف `index.html` وافتحه بأي متصفح — لا يحتاج تشغيل سيرفر ولا أي متطلبات أخرى.
