## ✨ الميزات

### 🕐 ساعة الأسماء الحسنى
- قرص دوّار عليه **الأسماء المئة كاملة** مشكولة بدقة، كل تكّة اسم جديد بالعربية والإنجليزية مع شرحه.
- **بطاقة النور لكل اسم**: المعنى الموثق + الدليل (آية أو حديث بمصدره) + دعاء بالاسم بمصدره — من «مختصر فقه الأسماء الحسنى» (البدر) و«التوحيد: أسماء الله الحسنى» (التويجري) ومن القرآن والسنة المؤكدة.
- انقر وسط الساعة لفتح بطاقة الاسم، أو اسمًا على الدرج لتنتقل إليه مباشرة.
- ثلاثة أشكال للساعة، ثلاثة خطوط للأسماء، لغة الدرج عربي أو English، سرعة من ثانية إلى عشر ثوانٍ.

### 📿 المسبحة
- مسبحة واقعية بخيط وإمام وشرابة وشاهدين، بصوت خرز محسّن واهتزاز عند كل نقرة.
- اختيار الذكر (٨ أذكار جاهزة + أذكارك المخصصة)، والهدف (٣٣ / ٩٩ / ١٠٠ / عدد مخصص)، ونمط يدوي أو تلقائي.
- خمس مسبحات (خشبية، زمردية، حجرية، لؤلؤية، سوداء) وثلاثة أحجام وثلاثة أشكال للخرزة.
- شاهد كل ذكر من القرآن والسنة يظهر أسفلها بمصدره.

### 🌙 نور اليوم — الشاشة الجديدة (v2.0.0)
أربع عشرة أداة ترافق المسلم في يومه خطوةً خطوة:

| الأداة | ماذا تفعل لك |
|---|---|
| 🎯 نية اليوم | «ما نيّتك اليوم؟» — ست نوايا سريعة (طلب العلم، بر الوالدين، تحسين الخلق، الصدقة، إتقان العمل، حفظ اللسان) كلٌّ مع حديثها، ويتابعها التطبيق معك طوال اليوم |
| ⏰ عملٌ لكل وقت | يقترح عليك العمل المناسب لوقتك الآن: من قيام السحر إلى أذكار الصباح إلى آية الكرسي قبل النوم |
| ⏱️ تحدي الدقيقة | أعمال صالحة تستغرق دقيقة واحدة بعدّاد دائري حيّ — تكسر عادة التأجيل |
| ✨ خريطة الخير | كل عمل صالح تسجّله يصبح نجمة تتلألأ في سماء خاصة بك — ومع الوقت تتشكل لك سماء من النجوم |
| 😤 أنا غاضب | زر يقودك لعلاج الغضب بالسنة في أربع خطوات: الاستعاذة، تغيير المكان، الوضوء، وتأجيل القرار |
| 🎁 بنك الخيرات | أفكار صالحة صغيرة قابلة للتنفيذ فورًا، تتجدد كل يوم |
| 🎲 ماذا أفعل الآن؟ | زر عشوائي يعطيك اقتراحًا نافعًا يناسب فراغك |
| 🔄 عاداتٌ عبادات | كيف تحوّل عملك ورياضتك ودراستك ونومك إلى عبادة بالنية الصحيحة — مع الدليل |
| 🤲 سجل الدعوات | سجّل أدعيتك، وعندما تستجيب اضغط «استجيبت» فتنتقل إلى قسم **«فضل الله عليّ»** |
| ⏳ كم بقي من عمري؟ | ليس للتخويف بل للتذكير: أسابيع متبقية، رمضانات متوقعة، جُمعات — ثم: ابدأ اليوم |
| 💛 القرآن وحالتي | قلق؟ حزن؟ خوف؟ همّ؟ — آيات تناسب حالك مع دعائها المسنون |
| 🌙 محاسبتي قبل النوم | أربعة أسئلة صادقة تُختم بها يومك: الفروض، الأذى، الذكر، العلم |
| 🔒 نورٌ بينك وبينه | عملك الخفي (صدقة سر، قيام ليل) يُحفظ ولا يُعرض أبدًا — لا إحصاءات ولا مشاركة |
| 📜 وصية اليوم | وصية واحدة متجددة من القرآن والسنة وكلام السلف بأسلوب بصري جميل |
| 📤 كن سببًا في الخير | شارك فائدة اليوم مع من تحب بنقرة واحدة (مشاركة النظام أو واتساب أو نسخ) |

> ✨ النجوم تُضاف تلقائيًا عند إتمام جولة التسبيح، وتحدي الدقيقة، والمحاسبة اليومية — وميزات التطبيق كلها تعمل من دون إنترنت.

### ⚙️ الإعدادات
- أذكار مخصصة، أصوات تفاعلية (٤ أصوات للمسبحة و٣ للساعة)، اهتزاز.
- **المظهر**: وضع ليلي ونهاري، خمس لوحات ألوان، أربعة أنماط للخلفية، ثلاثة أحجام للخط.
- كل اختيار يُحفظ تلقائيًا على جهازك.

## 🚀 التجربة

افتح الموقع مباشرة من:

```
https://USERNAME.github.io/REPO-NAME/
```

> استبدل `USERNAME` باسم مستخدمك على GitHub و`REPO-NAME` باسم المستودع. الرابط الصحيح يظهر في **Settings ← Pages** بعد التفعيل.

أو حمّل `index.html` وافتحه بأي متصفح — لا يحتاج سيرفرًا ولا أي متطلبات.

💡 **نصيحة للآيفون**: افتح الموقع في Safari ثم اضغط زر المشاركة ← **Add to Home Screen**؛ سيعمل التطبيق كتطبيق مستقل بشاشة كاملة، والمحتوى مُهيأ لينزل تحت شريط البطارية والشبكة دون تداخل.

## 📤 النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا **Public** باسم مثل `noor`.
2. ارفع ملف `index.html` (Add file ← Upload files ← Commit changes).
3. افتح **Settings ← Pages**، اختر Branch: `main` والمجلد `/ (root)` ثم Save.
4. بعد دقيقة يصبح التطبيق متاحًا على الرابط أعلاه.

## 🔄 كيف أُحدّث التطبيق لاحقًا؟

1. افتح المستودع على GitHub واختر `index.html`.
2. اضغط أيقونة القلم ✏️، أو ارفع الملف الجديد ليحل محل القديم.
3. اضغط **Commit changes** — يتحدّث الموقع تلقائيًا لكل الزوار خلال دقيقة.

## 🔒 الخصوصية

- **لا حسابات، لا خوادم، لا إعلانات، لا تتبع.**
- كل بياناتك (العدادات، الإعدادات، النوايا، الدعوات، النجوم، أعمالك الخفية) تُخزن في ذاكرة المتصفح على جهازك عبر `localStorage`، ولا تُرسل إلى أي جهة.
- حذف بيانات الموقع من المتصفح (أو زر «حذف» في الإعدادات ← البيانات) يمحوها نهائيًا.
- قسم «نورٌ بينك وبينه» لا يعرض ما تُدخله أبدًا ولا يخرج من جهازك.

## 🛠️ التقنيات

- HTML + CSS + JavaScript في **ملف واحد**، بلا مكتبات خارجية ولا بناء ولا سيرفر.
- أصوات مولَّدة محليًا بـ Web Audio API (بلا ملفات صوت).
- واجهة عربية RTL متوائمة مع الجوال أولًا (أندرويد وآيفون) مع دعم `safe-area` لشاشات النوتش.
- تقويم هجري عبر `Intl` (أم القرى).
