التوثيق

عن تطبيق نور
نور رفيق ذكر بسيط يعمل من دون إنترنت: ساعة تفاعلية تعرض أسماء الله الحسنى بالعربية والإنجليزية مع شرح موجز، ومسبحة إلكترونية بصوت الخرز وعدادات محفوظة. صُمم للهاتف أولًا ويُستضاف مجانًا عبر GitHub Pages.
ملاحظة: الحديث الشريف ذكر أن للأسماء «تسعة وتسعين» اسمًا، وفي الساعة مئة خانة لأننا أضفنا الاسم الأعظم «الله» إلى القائمة كما في اللوحات المشهورة، فتكتمل المئة.
الخصوصية
لا حسابات ولا خوادم ولا إعلانات ولا تتبع. عداداتك وإعداداتك وأذكارك المخصصة تُخزن في ذاكرة جهازك عبر المتصفح، وتظل محفوظة بعد الإغلاق. حذف بيانات الموقع من المتصفح يحذفها نهائيًا.
النشر والتحديث عبر GitHub
  1. أنشئ حسابًا على github.com ثم اضغط زر «+» أعلى الصفحة واختر New repository.
  2. سمِّه مثلًا noor، اجعله Public، ثم اضغط Create repository.
  3. في صفحة المستودع اختر uploading an existing file واسحب ملف index.html ثم Commit changes.
  4. افتح Settings ← Pages، واختر Branch: main والمجلد / (root) ثم Save.
  5. بعد دقيقة يصبح الموقع على الرابط: https://اسم-حسابك.github.io/noor/
  6. للتحديث لاحقًا: افتح المستودع، اختر index.html ثم أيقونة القلم، عدّل، واضغط Commit — يتحدث الموقع تلقائيًا لكل الزوار.
سجل الإصدار
v1.3.0 — لغة درج الأسماء: عربي أو English من الإعدادات، وإعادة تنسيق الدرج بحلقة مزدوجة وملاءمة تلقائية لعرض كل اسم فلا تداخل، ونبض قلبٍ حي داخل الساعة كما في المسبحة، وإظهار شاهد كل ذكر من القرآن والسنة في صفحة المسبحة.

v1.2.0 — اختيار صوت الساعة (تِك توك، جرس، خشبي) وصوت المسبحة (خرز، زجاج، خشب، ناعم)، واختيار شكل الساعة (كلاسيكي، مزخرف، بسيط) وشكل المسبحة (خشبية، زمردية، حجرية)، وخط لأسماء الله الحسنى (كوفي، نسخ، رقعة)، ظهور الشواهد على المسبحة، ونمط التسبيح اليدوي أو التحريك التلقائي، وعقرب ثوانٍ مع تدرّج متحرك ونبض قرب انتقال الاسم.

v1.1.0 — تحسين كامل لمقاسات الجوال (أندرويد وآيفون)، قرص الساعة كُتبت عليه الأسماء بخط رفيع جدًا بدل الدقائق والثواني، إظهار الشرح دائمًا، دقّات ساعة حقيقية (تِك وتوك)، سرعة من ١ إلى ١٠ ثوانٍ بمؤشر انزلاقي، ومسبحة خشبية واقعية بخيط وشرابة وصوت خرز محسّن.

v1.0.0 — الإطلاق الأول: ساعة الأسماء الحسنى (١٠٠ اسم مع الشرح)، المسبحة بصوت الخرز والاحتفال، أذكار مخصصة، إعدادات كاملة، حفظ محلي على الجهاز، وضع ليلي/نهاري، واهتزاز.
